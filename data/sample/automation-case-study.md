# Fictional internship: Northstar Media content assistant

Alex built a content assistant at the fictional Northstar Media during June to August 2025. It used the OpenAI API and n8n to coordinate research notes, draft generation, and editorial review. A React and TypeScript interface let editors trigger the workflow.

The fictional editorial team used the prototype to draft articles. Editors manually reviewed factual claims before publication. The case study documents adoption by that team, but no measured latency, cost reduction, or production SLA. It does not establish autonomous fact verification or web search implementation in CareerLens.

Alex's contribution covered the interface and API integration. The learning focus was prompt design, handling provider failures, and separating generated drafts from approved content. This case study is demo data only.
